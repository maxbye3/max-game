# Character Contribution Guide

Thanks for contributing a character to the game.

Please provide the following files and information.

**Important:** all filenames need to match the examples below **exactly**. If the filename is different, the game will not recognize it.

## 1. Avatar Reference

An avatar reference image is included with this guide.

Please review it and let me know about any small changes needed to make the character resemble you more closely.

## 2. `dialogue.txt`

Create a plain-text file called exactly:

`dialogue.txt`

Add whatever you want your character to say when the protagonist interacts with you.

If you want your character to have **multiple pieces of dialogue** when the protagonist talks to you more than once, put each piece of dialogue on a **new line**.

The game will work through them in order each time the protagonist interacts with your character.

For example:

`Hello there.`  
`You're back again?`  
`Seriously, how many times are you going to talk to me?`

Each new line will be treated as the next interaction.

## 3. Optional Profile Image — `profile.png`

You may provide a profile image that will be displayed while your character is speaking to the protagonist.

This can be a photo, illustration, alternative avatar, or another image that represents your character.

Please name the file exactly:

`profile.png`

A square or portrait-oriented image is preferred.

## 4. Optional Item Image — `item.png`

You may provide an image of an item that your character gives to the protagonist.

This could be something useful, strange, personal, or completely ridiculous.

Please name the file exactly:

`item.png`

A transparent PNG is preferred.

## 5. Optional Item Description — `item.txt`

If you provide an item, you can also describe what happens when the protagonist uses it.
Be as wild or surreal as you want. It might not work but I'll try to fix it after the suprise.
Please put this in a file named exactly:

`item.txt`

For example:

`Makes the protagonist move 20% faster.`

The effect can be practical, cosmetic, narrative, or comedic. It does not need to follow realistic logic.

If your item gives the protagonist a temporary power or effect, **it can last for a maximum of 20 seconds**.

## 6. Optional Theme Music — `theme.mp3`

You may provide a piece of theme music associated with your character.

This could be a song, sound, jingle, or anything else that feels appropriate.

It **must be an MP3 file** and must be named exactly:

`theme.mp3`

**Theme music will play for a maximum of 10 seconds**, so please choose something that works well as a short clip.

## Content Guidelines

Please keep submissions reasonably safe for work, unless the idea is hilarious to justify the risk.

Also, bear in mind that I am currently applying for a security clearance. Please avoid anything that could accidentally make me appear involved in anything that would be tedious to explain to an investigator.

## Keep It Secret

I will have no idea what any of you have submitted beforehand, so your dialogue, profile image, item, item effect, music, and anything else you contribute will be a surprise to me when I encounter it in the game (I'll do a stream).

If you have any questions, please keep them vague enough that they don't reveal what you're planning or if you want to contribute more.
